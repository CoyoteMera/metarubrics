# Metarubrics

Editor de metadatos de post — ALE, CSV, XLSX y CDL — que corre entero en el
navegador. Ningún archivo sale de tu máquina: no hay servidor, no hay subida,
no hay cuenta.

**→ [coyotemera.github.io/metarubrics](https://coyotemera.github.io/metarubrics/)**

## Qué hace

- Abre `.ale`, `.csv`, `.tsv`, `.txt`, `.xlsx`, `.xls`, `.cdl`, `.ccc`, `.cc`
- Edita como una hoja de cálculo: rangos, copiar/pegar, relleno, deshacer
- Buscar y reemplazar en toda la tabla
- Expande `ASC_SOP` en columnas de Slope / Offset / Power editables
- Utilidades de ALE: `Tracks → V`, `AuxTC1 → Sound TC`, detección de columnas
  vacías, resaltado de celdas sin rellenar
- Exporta a ALE, CSV, XLSX y CDL
